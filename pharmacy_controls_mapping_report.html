🏥 Pharmacy SaaS — UI Controls & Data Destinations Report

Functional Specification for Management, Settings & Compliance, and Reports & Analytics Modules

🏛️ 1. MANAGEMENT MODULE (Branches, Users/Staff, Roles, Permissions & Audit)
Screen Button / UI Control Type What This Button Does Where It Connects / Where It Saves Impact on Operations / POS
Branches isMultiBranch Toggle Toggle Switch Switches the software between Single-Shop mode (1 retail pharmacy) and Multi-Branch mode (multiple hospital branches/warehouses). Saved in Organization Profile in database settings. When OFF: locks cashier to Main Store. When ON: unlocks branch switcher and stock transfers.
Branches + Add New Branch Button Opens popup modal to register a new pharmacy store, hospital ward dispensary, or warehouse. Saves new record to Branches Database and adds card to on-screen list. Makes new branch immediately selectable in POS cashier dropdown and inventory stock views.
Branches Branch Type Dropdown Dropdown Selects format: Hospital Pharmacy, Retail Store, Central Warehouse, Clinic Dispensary. Saves to Branch Details. Options come from system master categories. If Central Warehouse: can receive distributor POs but blocks retail sales. If Hospital: enables inpatient prescription lookups.
Branches Invoice Prefix Field Text Input Defines the bill prefix code for this store (e.g. FIT-, PNE-, MUM-). Saved to Branch Profile and connects to the bill numbering sequence. Directly connects to POS Cashier Machine! Every bill printed at this counter starts with this code (e.g. PNE-1001).
Branches Drug License & GSTIN Text Input Enters statutory Drug License (Form 20/21) and 15-digit GSTIN number. Saved to Branch Profile in database. Automatically prints on top of every customer Tax Invoice header and GSTR-1 tax filings.
Branches Branch Status Dropdown Dropdown Sets store to Active or Inactive. Saves to Branch Status. If Inactive: removes store from cashier switcher so no one can cut bills at a closed branch.
Branches Edit Branch Button Row Button Opens modal pre-filled with branch details to update phone, address, manager, or hours. Overwrites and updates that specific branch in the Branches table. Immediately updates bill header address and contact numbers across all printed receipts.
Branches Deactivate / Delete Row Button Deactivates a branch from the pharmacy network. Marks status as 'Inactive' (Soft delete) in database. Prevents accidental data loss while immediately blocking new sales at that location.
Users & Staff + Add New Staff / Invite Button Opens employee registration form to create system login and assign roles. Saves new employee to Users Table and creates login credentials. Allows the new employee to log in to POS or Web ERP.
Users & Staff Role Dropdown Dropdown Assigns employee job role (Administrator, Pharmacist, Cashier, Inventory Manager). Saves to User Record. Options come from the Roles Module. Dictates which screens, menus, and buttons this employee is authorized to see and click.
Users & Staff Assigned Branches Checkboxes Multi-Select Selects which physical store locations this employee has permission to work at. Saves to Branch Assignment table in database. Controls which stores appear in this cashier's branch switcher dropdown on login.
Users & Staff 4-Digit Access PIN Text Input Sets a 4-digit quick passcode (e.g. 1234 or 0000). Saves to user profile in database. Connects to POS Cashier Screen for instant 1-second shift switching without typing email/password.
Users & Staff Deactivate Staff Button Row Button Immediately disables employee system access. Sets user status to 'Inactive' in database. Instantly blocks former employees from logging in or handling cash registers.
Roles & Permissions Select Role Dropdown Dropdown Selects which role's security rules you are configuring (e.g. Cashier vs Pharmacist). Loads permission states for that specific role. Allows fine-tuning permissions for cashiers independently from store managers.
Roles & Permissions Permission Cell Click Interactive Cell Cycles through 4 security states: Full Access (Green) ➔ Limited (Yellow) ➔ Blocked (Red) ➔ None (Grey). Updates permission matrix for that page and action. Controls button visibility (e.g. if 'Delete Bill' is Blocked for Cashier, the delete button disappears from POS).
Roles & Permissions Save Permissions Matrix Button Commits the entire security grid across all 7 modules to the database. Saves to Role Permissions Table in database. Immediately enforces authorization rules across POS, Android app, and Web ERP.
Audit Logs Action & Severity Filters Filter Filters logs by action (CREATE, UPDATE, DELETE, FINANCIAL) and risk level (Low, Med, High, Critical). Filters the Audit Logs View in database. Enables store auditors to instantly inspect high-risk events like voided bills and cash overages.
Audit Logs View Log Details Row Button Opens modal showing exact before-and-after values, IP address, and cashier identity. Reads metadata from audit log record. Provides tamper-evident legal proof of who modified medicine prices or stock quantities.
🧾 2. SETTINGS & COMPLIANCE MODULE (GST/Tax Configuration, Taxes Directory, Subscriptions)
Screen Button / UI Control Type What This Button Does Where It Connects / Where It Saves Impact on Operations / POS
Tax & GST GST Scheme Switch Pill Switch Toggles between Regular GST (Input Tax Credit) and Composition Scheme (Flat 1% Turnover Tax). Saves to Organization GST Profile in database. If Composition: retail bills will not display CGST/SGST line breakdowns; flat turnover tax is calculated.
Tax & GST Tax-Inclusive Pricing Toggle Switch Toggles whether medicine shelf MRP already includes GST or if GST is added on top at billing. Saves to Organization Settings. Directly connects to POS Billing Calculator! If ON: Price = MRP / 1.12. If OFF: tax is added on top.
Tax & GST Auto Interstate Split Toggle Switch Automatically splits tax into CGST+SGST (local sales) or IGST (out-of-state sales) based on customer state. Saves to Organization Settings. Connects to POS Billing Screen! If customer state code differs from store state code, charges IGST automatically.
Tax & GST Auto 18% SaaS GST Toggle Switch Applies standard 18% GST on software subscriptions and franchise billing. Saves to Organization Settings. Automatically appends HSN/SAC code 997331 on franchise and subscription invoices.
Tax & GST e-Invoicing Integration Toggle Switch Connects the pharmacy system to the Government NIC e-Invoice & e-Way Bill portal. Saves to Organization Settings. Automatically generates government IRN number and B2B QR code for wholesale invoices exceeding threshold.
Tax & GST Save GST Configuration Button Commits legal business name, trade name, state, GSTIN, and all 5 toggle rules. Saves to Organization Table in database. Updates business header details printed on all customer bills and monthly GST reports.
Tax & GST Apply to Billing Toggle Toggle Switch Turns an individual tax (like CGST 6%, SGST 6%, VAT 5%, Cess 1%) ON or OFF. Saves to Tax Rates Table (is_applied) in database. Connects to POS Checkout! Only taxes with 'Apply to Billing = ON' will be calculated on customer bills.
Tax & GST + Add New Tax Button Opens modal to create a custom tax (e.g. 1% State Disaster Cess or Municipal Tax). Saves new tax record to Tax Rates Table. Adds the tax to the master directory and makes it selectable on product entry and billing.
Subscriptions Billing Cycle Switch Toggle Switch Switches pricing between Monthly and Annual (with 2 Months Free discount badge). Updates pricing display and checkout calculation. Applies 2 months free discount when renewing software subscription on annual billing.
Subscriptions Upgrade to Plan Button Button Opens checkout modal to upgrade pharmacy tier (Starter ➔ Growth ➔ Enterprise). Saves to Subscriptions Table & payment gateway. Unlocks multi-branch features, extra staff seats, and warehouse modules upon payment.
📊 3. REPORTS & ANALYTICS MODULE (Inventory Valuation, Procurement Spend, Expiry Risk)
Screen Button / UI Control Type What This Button Does Where It Connects / Where It Saves Impact on Operations / POS
Inventory Reports Export CSV Button Button Compiles category valuation and fast-moving medicines into a spreadsheet. Downloads 'inventory_valuation.csv' directly to user's computer via browser download. Provides pharmacy accountant with raw spreadsheet for stock audits and P&L balance sheet.
Inventory Reports Print / Export PDF Button Formats valuation report into a clean, printable branded layout. Connects to Browser Print Window / Printer for 1-click printing or PDF save. Generates official stock valuation document for bank loan audits and tax verifications.
Inventory Reports Reorder Stock Button Row Button Identifies fast-moving medicines running out of stock and initiates purchase order. Navigates directly to Purchases Screen with medicine name and quantity pre-filled. Prevents stockouts by turning demand forecast directly into a supplier purchase order.
Procurement Reports Export CSV Button Button Exports distributor spending, delivery lead times, and fulfillment accuracy percentages. Downloads 'vendor_procurement_analytics.csv' to user's computer. Allows pharmacy owner to compare distributor pricing and delivery performance in Excel.
Procurement Reports Create Purchase Order Button Quick shortcut to issue a new stock order to top-performing vendors. Navigates to Purchases Screen with vendor pre-selected. Speeds up restocking with verified distributors.
Expiry Risk Reports Risk Filter Badges Filter Badges Filters batches by urgency: Critical (<30 days), High Risk (<90 days), Medium (<180 days), Expired. Filters active on-screen expiry table. Allows chief pharmacist to prioritize clearing stock before it turns into dead loss.
Expiry Risk Reports Return to Vendor Button Row Button Initiates credit return for expiring medicines back to distributor. Navigates to Supplier Returns Screen with batch number and vendor pre-filled. Recovers pharmacy money by returning unsold medicines before expiry date.
Expiry Risk Reports Transfer Stock Button Row Button Moves near-expiry medicines from a slow store to a busy hospital store to sell before expiry. Navigates to Stock Transfer Screen with medicine and batch pre-filled. Ensures stock gets sold at high-traffic counters instead of expiring on the shelf.
Expiry Risk Reports Export CSV & Print PDF Buttons Exports complete batch expiry audit list with cost valuations and expiry dates. Downloads '.csv' or prints PDF document. Mandatory compliance report for government FDA drug inspector visits.
